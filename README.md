# BlogCraft

An AI-powered blog generation app using Llama2, Streamlit, LangChain, and Hugging Face.

## Features
- Generate blog posts with custom length and tone.
- Interactive UI built with Streamlit.
- Llama2 hosted on Hugging Face.

## Setup
1. Clone the repo
2. Create and activate a virtualenv
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
